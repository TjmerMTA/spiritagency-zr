# zr.spiritagency.space

Сателлит агентства Spirit: страница «Скільки заробляють на OnlyFans в Україні».

- Сайт статический, лежит в `site/` — править можно прямо там.
- Выкладка: `./deploy.sh` заливает `site/` в ветку `gh-pages`, оттуда его отдаёт GitHub Pages.
- Домен: `site/CNAME`. В DNS нужна запись `CNAME zr → tjmermta.github.io`.
- Кнопки заявок ведут в Telegram агентства.

Откуда взят: написан заново 03.10.2026 на стилях темы Spirit Start. Исходная страница (сделана 28.08.2026 прямо на хостинге) не сохранилась — известны были только тема, заголовок и состав разметки; тексты новые.
